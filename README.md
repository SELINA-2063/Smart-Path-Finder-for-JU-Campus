# Smart Path Finder for JU Campus

A web-based campus navigation system designed to help users find the shortest path inside Jahangirnagar University campus.

## Features
- Find shortest routes between locations
- Interactive navigation interface
- User-friendly design
- Fast path calculation

## Technologies Used
- HTML
- CSS
- JavaScript
